## 23. Known Behavior: SID 1000003

SID `1000003` is intentionally broad:

```text
alert http any any -> any any
```

The rule can generate alerts from normal HTTP traffic.

This behavior is expected and demonstrates that broad IDS rules can  
produce additional alert noise.

The rule remains enabled because it is useful for demonstrating the  
difference between broad detection and precise detection.

The Lightweight Suricata IDS Lab successfully passed functional testing  
across the complete detection and visualization pipeline.

The validation confirms that Suricata can detect the custom laboratory  
traffic, generate EVE JSON events, forward them through Grafana Alloy,

Grafana.

The testing also confirmed the expected behavior of broad and precise  
detection rules and demonstrated the importance of rule refinement in  
reducing alert noise.
